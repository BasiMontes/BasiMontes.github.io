  1. Laboratorio de flaky tests

    En curso

    Catálogo de causas de inestabilidad en pruebas automatizadas, con reproducción mínima de cada causa y medición por repetición (100 ejecuciones por caso).

    • Playwright
    • TypeScript
    • Flakiness
    • Diagnóstico

  2. Contrato de API: que el servidor cumpla lo que promete

    Terminado

    API de práctica de reservas de pistas deportivas, con su especificación OpenAPI como fuente de verdad. Las pruebas validan cada respuesta contra el contrato y comprueban las reglas de negocio: horario, solapes, límites por usuario y cancelación. Varias reglas clave se han comprobado rompiéndolas a propósito para verificar que sus pruebas fallan.

    Ver el repositorio

    Ver la web

    • Playwright
    • TypeScript
    • OpenAPI
    • Node.js
    • CI/CD

  3. BuggyBank: verificar el resultado real

    Terminado

    Pruebas de transferencias en un banco de práctica con fallos sembrados. Cada prueba comprueba el débito, el crédito y el movimiento registrado, no solo el mensaje de éxito. Hallazgo propio: las transferencias de importe entero de 500 o más se aplican dos veces; lo acoté con valores límite (499 no, 500 sí).

    Ver el repositorio

    • Playwright
    • TypeScript
